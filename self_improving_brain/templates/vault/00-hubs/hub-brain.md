# Brain

This vault is a memory that your agents read and write. It gets better every session:
recall learns which notes are really needed, and your corrections become lessons.

## Where things go
- `00-hubs/` - one entry point per topic. A hub carries the current state and links its notes.
- `10-projects/` - things with an end: goals, status, next steps. Hub: [[hub-projects]].
- `20-areas/` - lasting knowledge: decisions, how-tos, pitfalls, preferences.
- `30-resources/` - references, sources, links.
- `90-entities/` - short stubs for systems, tools and people, so others can link instead of re-explaining.
