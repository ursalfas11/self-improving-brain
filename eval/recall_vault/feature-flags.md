# Feature flags with gradual rollout by percentage

## Using flags
New behaviour ships behind a flag that is off. Turn it on for staff first, then for five percent of customers, then everyone.

## Cleanup
A flag that has been fully on for two weeks must be removed from the code. Stale flags make the tests lie.
