# Umzug der Anwendungen auf neue Server

## Vorbereitung
Vor dem Umzug werden Domains auf kurze Gültigkeit gestellt und die Datensicherung geprüft.

## Umzugsnacht
Der Umzug findet nachts am Wochenende statt. Nach dem Umschalten laufen die Tests gegen die neuen Server.
