# Product images: allowed formats, size limits and naming

## Formats
Upload JPEG or PNG, at least 1500 pixels on the long side, at most 10 megabytes. Transparent backgrounds only for PNG.

## Naming
File names start with the article number, then an underscore and a running number. The first image is the main image in the shop.
